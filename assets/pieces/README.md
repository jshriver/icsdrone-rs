# Piece sets

Each folder is one set, named `<color><piece>.svg`: color `w`/`b`,
piece `K` king, `Q` queen, `R` rook, `B` bishop, `N` knight, `P` pawn.
All are compiled into icsdrone-rs (AGPLv3+, see `../../LICENSE`); each
keeps its own license, below.

## From Armando Marroquin's diagram fonts

Converted from the TrueType chess diagram fonts by Armando Hernandez
Marroquin (Colegio La Salle de San Cristobal, Chiapas, Mexico), as
bundled with [Chess Image 2](https://github.com/rchastain2/chess-image-2),
by `tools/ttf_pieces.py`: each glyph's outline as SVG, with a white
silhouette added under it so white pieces are solid. Each font's
readme says it is freeware ("You can use them freely").
