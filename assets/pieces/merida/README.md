# merida chess pieces

SVG chess piece set by Armando Hernandez Marroquin, licensed under the
[GNU GPL, version 2 or later](https://www.gnu.org/licenses/gpl-2.0.txt).
Used here under GPLv3, as part of icsdrone-rs.

Source: the Lichess repository,
<https://github.com/lichess-org/lila/tree/master/public/piece/merida>
(license listed in its `COPYING.md`).

Files are named `<color><piece>.svg`: color `w`/`b`, piece
`K` king, `Q` queen, `R` rook, `B` bishop, `N` knight, `P` pawn.
